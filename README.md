#  Movie Genre Classification using Machine Learning

##  Project Overview

This project aims to build a Machine Learning model that predicts the genre of a movie based on its plot summary or other textual information.

The project uses Natural Language Processing (NLP) techniques to process textual data and Machine Learning classification algorithms to predict movie genres.

This project is completed as **Task 1** of the CODSOFT Machine Learning Internship.

##  Objectives

- Predict movie genres based on plot summaries.
- Apply Natural Language Processing techniques to textual data.
- Convert text into numerical features using TF-IDF.
- Train and evaluate Machine Learning classification models.
- Understand the practical applications of text classification.


